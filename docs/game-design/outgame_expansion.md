# アウトゲーム拡張案 — 提案ドラフトの穴埋め

対象:提案ドラフト(インゲーム/リザルト/アウトゲーム)のうち、アウトゲーム部
現状の記載:強化抽選+もう1回 / 確定チケット / 差分表示 / 一括最強装備+オーラ

---

## 1. 診断:なぜアウトゲームだけ薄いのか

ドラフトのインゲームとリザルトは密度が高い。アウトゲームが薄いのは案の不足ではなく、**構造上そうなるように設計されているから**である。

### 根本原因:リザルトで全てが確定している

現ドラフトの流れは次の通り。

```
拾う(色だけ判明) → リザルト(中身が全部判明) → アウトゲーム(確定済み在庫の処理)
```

アウトゲームに到達した時点で**未確定要素が強化抽選しか残っていない**。パチンコで言えば「出玉を換金するだけの場所」であり、台が1台しかない状態に等しい。だから案が出ない。

対策は演出を足すことではなく、**リザルトで確定させる範囲を意図的に狭め、未開封をアウトゲームまで持ち越すこと**である。これだけでアウトゲームが「開ける台のある場所」に変わり、以下の案が全て成立するようになる。

### 4つの構造的欠落

| # | 欠落 | 症状 | 埋める案 |
|---|---|---|---|
| 1 | **未開封が残らない** | アウトゲームに抽選が強化しかない | 未開封箱ストック / 鑑定(第2抽選) |
| 2 | **蓄積が見えない** | 「今回の伸び」は見えるが「ここまでの伸び」が見えない。ハクスラの快感は累積の可視化から来る | ドル箱倉庫 / 戦闘力推移グラフ / 図鑑 |
| 3 | **強さが数字止まり** | 非即時反映なので「強くなった」を体で確かめる場がどこにもない | 試し斬りダミー / タイムアタック |
| 4 | **4人マルチなのに社会装置がゼロ** | 強さは見られて初めて完成する。ロビーが機能していない | 装備披露 / 祝福テロップ / パーティ合計戦闘力 |

## 2. 追加案(提案ドラフトに貼れる形式)

### A. 未開封をアウトゲームに残す

- **未開封箱のストック**
  - 保留のうち一定数は**中身を確定させずに「箱」として持ち帰る**
  - 倉庫に箱が物理的に積み上がっていく
  - 好きなタイミングで開けられる。溜めることもできる
  - **まとめ開封**:10個以上溜めて一斉に開けると、画面いっぱいに光柱が乱立する専用演出
    - ドル箱を一気に流す快感。動画映え・配信映えする
    - 「開封数ボーナス」で溜めるほど得になる設計にすると、溜める動機が生まれる
  - ログインのたびに「開けていない箱がn個」が待っている状態を作れる

- **鑑定 = 第2抽選**
  - リザルトで確定するのは**本体レア度と基礎ステータスだけ**にする
  - サブステータス(刻印)はアウトゲームの鑑定で改めて抽選
  - 候補を1つずつ開示し、途中で止めるか続けるか選べる
  - 1つのアイテムから抽選機会を2回取り出せる。ドロップ数を増やさずに体験を倍にできる
  - 未鑑定でも装備可能にして、強制作業にしない

- **ミミック箱**
  - 低確率で箱から敵が出てくる
  - 制限時間内に倒せば中身が倍、逃すと半減
  - アウトゲームに1回だけアクションが差し込まれる異物感が記憶に残る

- **査定演出**
  - 拾った装備を自動で「S / A / B / C」格付けする
  - 判定そのものをルーレット演出にすると、確定済みの情報でも1回ぶんの開示体験になる
  - 大量の装備を捌く作業が、演出付きの流れ作業に変わる

### B. 蓄積を陳列する

- **ドル箱倉庫**
  - 帰還するたびに倉庫に箱が積まれる。レア度で箱の色が変わる
  - 累積の高さがそのまま「ここまでやってきた量」の証になる
  - ロビーの背景にも積み上がり、他人から見える

- **戦闘力の推移グラフ**
  - ホームに右肩上がりの折れ線。「1週間前の自分」との差分を常時表示
  - **「どんどん強くなっている感」を最も直接的に可視化する案**
  - 伸び悩んだ時期が見えるのは逆効果なので、グラフは常に単調増加する指標(最高到達値)で描く

- **装備図鑑**
  - 「金装備 12 / 40 収集」のプログレス表示
  - **あと1〜2個で埋まる列を意図的に作る**とニアミスが働く
  - コンプ報酬は恒久バフでなく称号や見た目にして、コンプ強制圧を下げる

- **「初めての◯◯」の刻印**
  - 初の金装備、初の虹装備、初の強化大成功に専用演出と日付入り称号
  - 後から見返せる記録として残る

- **計数機演出**
  - 不要装備をまとめて売却するとき、数字がガラガラ回って加算される
  - 処分作業そのものを報酬体験に変える

### C. 「強くなった」を体で確かめさせる

- **試し斬りダミー(最推奨)**
  - ロビーに殴れるカカシを置く。装備変更直後に殴るとダメージ数字が出る
  - **前回記録との差分を「+2,400」で表示**
  - 非即時反映で最も失われる「手応え」を、アウトゲームで直接取り返せる
  - 実装が軽く、効果が大きい。4人で同時に殴れるようにすると比べ合いが起きる

- **タイムアタック的な提示**
  - 「前回のボス、この装備なら n 秒で倒せる」を自動計算して表示
  - 数値ではなく時間で見せると、強さが直感的になる

- **次の壁の可視化**
  - 「次ステージ推奨値まであと ◯」のバー
  - 一括装備で戦闘力が上がった**直後**に見せる。達成感がそのまま次ランの動機に変換される

### D. 回せる台を増やす・深くする

- **強化の天井**
  - n回失敗で次回は成功確定。残り回数を常時表示
  - **失敗が「天井が近づいた」に意味変換される**。カジュアル救済と射幸性を同時に満たす
  - 「あと2回で天井」という状態がそれ自体ニアミスとして機能する

- **強化の連鎖ボーナス**
  - 連続成功で倍率が乗る。3連続で大成功確率アップ
  - 「もう1回」を押す理由が増える

- **装備を喰わせる(継承)**
  - 古い装備を新しい装備に喰わせると、サブステが一部引き継がれる
  - **捨てる罪悪感が消え、かつ抽選機会が1回増える**
  - ハクスラの「倉庫が溢れる」問題の解決も兼ねる

- **刻印の付け替え**
  - 良いサブステだけを抜き取って別の装備に移せる
  - 厳選に終わりがなくなる。上級者向けの深さを低コストで追加できる

- **同種2個で色替え・覚醒**
  - 同じ装備を2個持つと見た目を変えられる、あるいは上限突破できる
  - ダブりが「損」から「素材」に変わる

- **今日の一振り**
  - 1日1回だけ無料で回せる抽選。ログイン動機として機能する
  - チケットと役割が重複しないよう、こちらは**装備ではなく強化素材**を出す等で棲み分ける

### E. 社会装置(4人マルチの未活用資産)

- **ロビーでの装備披露**
  - 他人のキャラに戦闘力と「今日の最高ドロップ」が表示される
  - 最上位装備は発光し、近づくと詳細を見られる
  - 表示は戦闘力と最高ドロップに限定してマウントを抑止する

- **祝福テロップ**
  - 誰かが最上位を引く、強化大成功する、天井を叩くとロビー全体にテロップが流れる
  - 他人の当たりが自分の期待になる。ホールの大当たり音と同じ構造

- **パーティ合計戦闘力**
  - 出撃前に4人の合計がカウントアップ
  - 「今日一番伸びた人」を自動表示。**絶対値ではなく伸び率**で判定して初心者にも回す

- **見せ合いタイム**
  - 出撃前の10秒、各自の新装備が自動でハイライトされる
  - スタンプで反応できる。強制でなく眺めるだけで成立する尺に収める

### F. 継続と救済

- **確変の独立化**
  - ドラフトではチケット案の中に「ドロップ率UP中 残り3回」が混ざっている。これは独立した仕掛けとして切り出す価値がある
  - 最上位を引いた直後から次の3ラン、ロビーの色とBGMが変わり、ドロップ率が上がる
  - **失効の単位は時間ではなくラン数にする**。時間制限は生活を人質に取る設計であり、カジュアルタイトルには過剰

- **連チャンバッジ**
  - 「n連続のランで金以上」をホームに表示。途切れると消える
  - 途切れる恐怖が次のランを呼ぶ

- **分解 → 素材 → 合成**
  - 不要装備を分解して素材化し、素材を合成抽選に再投入できる
  - **下振れしたランの救済**として機能する。カジュアル層の離脱防止に効く

- **未消化の呼び声**
  - 未開封の箱、未鑑定の装備、装備可能な上位品がある間、該当メニューが脈動する
  - ホームのキャラが装備を見て振り返る待機モーションを足すと、放置耐性が下がる

## 3. 提案に足すなら、この4つ

多数を並べるより、構造的欠落を1つずつ潰す4案に絞るのが強い。

| 優先 | 案 | 埋める穴 | なぜこれか | 実装コスト |
|---|---|---|---|---|
| **1** | **未開封箱ストック + まとめ開封** | 欠落1 | アウトゲームに抽選を持ち込む唯一の根本策。これを入れないと他の案が全部「おまけ」になる。まとめ開封は演出の山としても最大 | 中 |
| **2** | **試し斬りダミー** | 欠落3 | 非即時反映というこの企画最大のハンデを、最も低コストで直接埋める。数字ではなく手応えで「強くなった」を返す | 小 |
| **3** | **強化の天井 + 連鎖ボーナス** | 欠落1の補強 | 既にある強化抽選に乗せるだけ。失敗の意味を反転させられるので、カジュアル成立性も同時に上がる | 小 |
| **4** | **戦闘力推移グラフ + ドル箱倉庫** | 欠落2 | 企画テーマ「どんどん強くなっていっている感」への直球の回答。単発の伸びではなく累積を見せる | 小〜中 |

欠落4(社会装置)は効果が大きいが、ロビー同期の実装が重く、P0/P1が動いてからで良い。

## 4. ドラフトへの修正提案(2点)

### 修正1:リザルトで全部を確定させない

```diff
- 拾う(色だけ判明) → リザルト(中身が全部判明) → アウトゲーム
+ 拾う(色だけ判明) → リザルト(本体レア度と基礎ステのみ判明)
+                 → アウトゲーム(未開封箱を開ける / 鑑定でサブステ抽選)
```

この1点の変更が、アウトゲーム案全体の前提になる。

### 修正2:チケット案の分解

現ドラフトのチケット項目には、性質の違う3つが混在している。

| 現在の記載 | 実際の正体 | 置き場所 |
|---|---|---|
| 保留1個を金以上確定にするチケット | 消費アイテム | アウトゲームのまま |
| 「ドロップ率UP中 残り3回」 | 状態の継続(確変) | **独立した仕掛けに切り出す** |
| 「+123 ↑」の差分表示 | 装備比較UI | **一括最強装備ボタンの項目に移す** |

分けたほうが提案として読みやすく、それぞれの効果も測りやすい。

## 検証ブロック

**妥当性**:アウトゲームが薄い原因を「案の不足」ではなく「リザルトで確定が完了する構造」に帰着させた診断は、ドラフトの流れから直接導ける `[ESTIMATE]`。各追加案の効果量は未計測 `[HYPOTHESIS]`。

**制約**:未開封箱を導入するとリザルトの情報量が減るため、リザルト側の演出(RS群)の見せ場が弱まる可能性がある。本体レア度の確定はリザルトに残すことで、山は維持できる想定。図鑑・刻印・継承は上級者向けの深さであり、カジュアル層には複雑さのコストになるため導入順に注意を要する。

**改善余地**:未開封箱として持ち帰る比率(全ドロップの何割か)、まとめ開封のボーナス設計、天井回数、試し斬りダミーの比較基準(前回装備か、そのランの開始時か)。

**次アクション**:修正1(確定範囲の縮小)を先に意思決定する。ここが決まらないとアウトゲーム案は確定しない。決定後、優先度1〜2の2案でプロトタイプを組み、アウトゲーム滞在時間と再出撃率を計測する。
