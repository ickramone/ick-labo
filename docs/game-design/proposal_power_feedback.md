# 成長実感ブースト施策 提案

対象:4人マルチ / ハクスラ / カジュアルアクション
制約:マルチのため、ドロップアイテムはインゲーム中に即時反映しない

---

## 基本方針:即時反映しないことを、逆に武器にする

ドロップを即座に装備できないという制約は、通常は「その場で強くなる快感が得られない」という欠点として扱われる。本提案では、この制約を**「期待を溜める仕組み」として積極的に利用する**方針を採る。

参考にするのはパチンコ・パチスロの構造である。それらの快楽は「入賞して保留が溜まる」「保留が1つずつ変動して開示される」「出玉が積み上がる」という3段階でできており、これは本作の3シーンにそのまま対応する。

| 遊技機 | 本作 | そのシーンの役割 |
|---|---|---|
| 入賞・保留が溜まる | **インゲーム** | 期待を積む |
| 変動・予告・大当たり | **リザルト** | 開ける |
| 出玉・ドル箱・確変継続 | **アウトゲーム** | 強さに変え、次へ送り出す |

重要なのは、拾った瞬間に中身が分からないことを「情報がない状態」にせず、**「中身は不明だが期待度だけは見えている状態」**に設計することである。これによりプレイヤーは、ランの最中ずっと「早く開けたい」という未消化の期待を抱え続けることになる。

# 1. インゲーム — 期待を積む

インゲームの役割は、アイテムそのものを与えることではなく、**リザルトで開けるための「期待の在庫」を積み上げること**にある。ここで積んだ量と質が、そのままリザルトの熱量になる。

## 1-1. HUDの保留ストック表示

拾ったアイテムは、HUD上に色付きのアイコンとして順に積まれていく。表示されるのは**レアリティを示す色だけ**で、武器種も名前も数値も分からない。中身はリザルトで初めて判明する。

さらに一定確率で、**色を持たない「?」のアイコン**が出現する。これは何色か分からない状態であり、最高レアを含みうる枠として、通常のどの色よりも高い期待値を持つように設計する。

この仕組みが本提案全体の土台になる。プレイヤーはランを進めるほどHUDの下端にアイコンが増えていき、「今日はいい並びだ」「?が2個ある」といった具合に、**戦闘中ずっと自分の手持ちを意識し続ける**。拾う行為が単なる回収作業ではなく、期待の入金になる。

色だけは即座に見せる点が重要である。何の情報も与えないと、アイテムを拾ったときの手応えが完全に失われ、アクションのテンポそのものが削がれてしまう。隠すのは中身であって、期待度ではない。

**枠の拡張**:特定の条件を達成するとストックの上限枠が1個増える。この条件はパーティ単位の達成(全員が一定数撃破、ノーダメージでボス撃破など)にすると、枠の拡張そのものが協力の動機になる。器が大きくなること自体が報酬として機能する。

## 1-2. ドロップ倍率表示とRUSH突入

画面上部に「DROP ×1.0」のような倍率表示を常時出す。これはドロップ率、あるいは高レア出現率を示す数字であり、戦闘中の行動に応じてリアルタイムで上下する。

**上昇条件**はノーダメージ状態での敵撃破とし、被弾していない間だけ加算されていく。また、敵からまれにドロップする「確変アイテム」を拾うことでも加算される(これもノーダメージ中のみ有効)。この数字は**パーティ全員で共有**され、4人の誰の働きでも上がる。

倍率が×3.0に到達すると**「RUSH」に突入**する。全画面の確定演出が入り、画面の色調が変わり、キャラクターには確変中であることを示すエフェクトがまとわりつく。RUSH中はドロップ率が跳ね上がる。

この仕掛けの意図は、**射幸性をアクション操作そのものに接続すること**にある。数字が回っている限りプレイヤーの手は止まらず、「今この倍率を落としたくない」という維持動機が、避ける・攻めるという操作の質を直接引き上げる。共有方式にしているため、上手いプレイヤー1人が牽引でき、苦手なプレイヤーも同じRUSHの恩恵に乗れる。競争ではなく共犯関係が生まれる。

**減少ルールについて**:倍率を「被弾で即座に減らす」方式も考えられるが、カジュアル4人マルチでは下手なプレイヤーを罰する構造になり、パーティの空気を悪くする危険がある。**減少は時間経過による緩やかな減衰のみとし、被弾は「加算が止まる」に留める**ことを推奨する。ドロップ率をバー表示にして被弾で目減りさせる案は、より緊張感の高いチューニングを狙う場合の選択肢として保持しておく。

**ゾーン突入**:ステージ中にランダムで「ドロップ率UPゾーン」が発生する。画面の縁が発光しBGMが転調することで、RUSHとは別軸の「今ここで稼ぐべき区間」を作る。これは確変本体ではなく**前兆**として機能し、プレイヤーに「何か起きそうだ」という予感を与える役割を持つ。

## 1-3. ストックの昇格

確変アイテムを一定数獲得すると、**HUDに表示されている保留アイコンのレアリティが上がる**。紫だったアイコンが金に変わる専用演出が入り、専用のSEが鳴る。

これはパチンコの「保留変化」に相当する仕掛けである。既に手に入れたはずのものが後から良くなるという体験は、新しく1個拾うよりも記憶に残りやすい。「さっき拾った微妙なやつが金になった」という出来事は、そのランの記憶として強く残る。

実装上は、アイテムの最終的なレアリティは取得時点で確定させておき、**初期表示を意図的に低く見せておく**形になる。ここで守るべき原則は、**昇格は必ず上方向にしか起こさないこと**である。高く見せておいて後から下げる「降格フェイク」は、遊技機の文法を学習していないカジュアル層には「騙された」としか受け取られず、離脱要因になる。降格が存在しないなら、初期表示は「最低保証値」として説明でき、演出としての正当性も保てる。

## 1-4. ストック満タン告知

ストックが上限に到達すると「満タン」の告知が入り、同時にレアリティ変更の演出が発生する。上限まで積み上げたこと自体が報酬になる設計である。

満タン後にさらに拾ったアイテムについては、**仲間のストック枠に入っていく**仕様を推奨する。これには2つの利点がある。第一に、拾ったものが無駄になるという損失感が発生しない。第二に、**自分が拾ったアイテムが仲間を強くする**という協力の実感が、目に見える形で生まれる。4人で遊ぶ理由が、ここで1つ増える。

## 1-5. ドロップまでの「間」

敵を倒してからアイテムが落ちるまでに、意図的に「間」を置く。この**間が長いほど高レアである**という対応関係を作る。

プレイヤーはこれを説明されなくても数ラン以内に体得する。敵が倒れた後に一拍空くと、それだけで「何か来る」と身構えるようになる。**演出の長さそのものが情報として機能する**状態を作ることが目的であり、これはリザルトのタメ演出(2-1)と同じ文法で統一しておくと、学習が1回で済む。

## 1-6. オーバーキルによるレアリティ上昇

敵のHPを削り切った際の超過ダメージ量に応じて、ドロップするアイテムのレアリティが上がる。

これは**アクションの上手さを報酬に直結させる**仕掛けである。倍率表示(1-2)が「継続」を評価するのに対し、オーバーキルは「瞬間火力」を評価する。とどめの一撃に大技を合わせる、という明確なプレイ目標が生まれ、戦闘の組み立てに意味が加わる。

## 1-7. 一発告知音

最高レアのドロップには、**説明の要らない単音のSE**を割り当てる。派手な演出を重ねるのではなく、その音が鳴った瞬間に全員が「出た」と分かる音にする。

さらに、**他プレイヤーのドロップ音も聞こえる**ようにする。4人マルチで最も価値のある資産は、他人の当たりを共有できることである。隣で音が鳴れば自分の期待も上がる。これは単独プレイでは絶対に作れない構造であり、実装コストに対する効果が極めて大きい。

## 1-8. 虹エフェクトの敵

通常の敵の中に、まれに虹色のエフェクトをまとった個体が混ざる。この個体を倒せば**高レア以上が確定する**。

ここまでの仕掛けが全て「運が向こうからやってくる」ものであるのに対し、これは**プレイヤーが能動的に狙える確定**である。画面の向こうに虹の敵を見つけた瞬間、4人の意識が一斉にそこへ向く。運任せの体験の中に、狙う対象を1つ置いておく意味は大きい。

なお、この個体は逃走させない設計にする。取り逃がしはストレスにしかならない。

# 2. リザルト — 開ける

リザルトは本提案における**唯一の開封儀式**である。インゲームで積んだストックは、ここで全て中身が判明する。アイテムの内容を分割してアウトゲームに持ち越す案も検討したが、**開封体験を1箇所に集中させたほうが演出の山が際立つ**ため、リザルトに全て寄せる方針とする。

## 2-1. ストックの1個ずつ開示

ストックは一度に全部を表示せず、**1個ずつ順番に開示**する。低レアのものは短く流し、高レアのものは開示前の「タメ」を長く取る。さらにレアリティが確定した後で、**もう一段上に変化する**演出を入れる。

この緩急自体が情報になる。プレイヤーは数回のリザルトで「遅い=熱い」を学習し、以降は演出が減速しただけで心拍が上がるようになる。何を見せるかではなく、**どの速度で見せるかで感情を操作する**のがこの仕掛けの本質である。

インゲームのドロップの「間」(1-5)と同じ文法にしておくことで、プレイヤーは1つのルールを覚えるだけで両方のシーンを読めるようになる。

## 2-2. 一発告知

開示の途中、前触れなく**画面の隅が「ピカッ」と光る**。これが光ったら最高レア確定である。

通常の演出は段階を踏んで盛り上げていくが、これは逆に、何の前触れもなく結論だけが提示される。長い演出に慣れたプレイヤーほど、この唐突さに強く反応する。**演出体系の中に1つだけ異物を置く**ことで、全体のパターンが読み切られるのを防ぐ効果もある。

## 2-3. 復活

全てのストックを開示し終え、画面が「終了」に向けてフェードアウトしかけたその瞬間、**暗転から「!!」で追加枠が飛び出す**、あるいは既に開示済みのアイテムのレアリティが上がる。

期待がゼロまで落ちた直後の反転は、同じ報酬でも体感価値が大きく変わる。発生率は低く抑えてよい。低頻度であっても一度体験すれば記憶に残り、以降は毎回のリザルトで「まだあるかもしれない」という余韻が働き続ける。

運用上の注意として、**スキップ操作中でも復活は必ず割り込ませる**。スキップしたせいで見逃したという体験は、演出の価値を損なうだけでなく不信感につながる。

## 2-4. 予告の多層化

開示の前後に、カットイン、背景色の変化、BGMの転調、文字予告を重ねて配置する。文字予告には**「激」「確」といった漢字1文字を画面に叩きつける**表現を用いる。

個々の予告に固有の信頼度を設定し、それらが重なるほど期待度が上がる構造にする。プレイヤーはやがて「この背景色でカットインが入ったら濃厚」といったパターンを自力で読み解くようになり、**演出を読むこと自体が遊びになる**。これは遊技機の予告体系が長年機能してきた理由でもある。

ただし漢字予告のような強い表現は多用すると価値が下がるため、全開示のうち2割程度に抑える。

## 2-5. 運用ルール

リザルトは繰り返し通過する画面であるため、演出の強度とテンポの両立が必要になる。以下を設計の前提として定める。

- **全体の尺の上限を決める**。長いと2周目以降に必ずスキップされ、演出投資が無駄になる。
- **スキップは可能にする**。ただし**高レア開示の瞬間だけは1秒弱スキップ不可**とし、見せ場だけは必ず通す。
- **降格は作らない**。1-3と同じ原則で、変化は必ず上方向のみとする。

**4人分の開示方法について**:本ドラフトでは未決定だが、4人を順番に開示すると単純に待ち時間が4倍になる。**4分割で同時に変動させ、誰かが最高レアを引いたときだけその人のカットインが全画面に割り込む**方式を推奨する。待ち時間を抑えたまま、祭りの瞬間だけを作ることができる。

# 3. アウトゲーム — 強さに変える

アウトゲームの役割は、リザルトで確定したアイテムを**実際の強さに変換し、その伸びを目に見える形で示し、次のランへ送り出すこと**にある。インゲームとリザルトで溜めた期待を現金化する場所である。

## 3-1. 強化抽選

武具やスキルの強化は、**成功 / 大成功 / 失敗**の抽選演出を伴う形にする。抽選結果が出た直後、**同じ画面上に「もう1回」ボタン**を出し、続けて回せる導線を最短にする。

これはアウトゲームに「回し続けられる台」を置く仕掛けである。ドロップと違い、強化はプレイヤーの意思で何度でも回せる。ここが機能するかどうかで、アウトゲームの滞在時間が大きく変わる。

**天井**:一定回数失敗すると次回は成功が確定する。残り回数を「あと2回で天井」と常時表示する。この仕組みの価値は救済にとどまらない。**失敗の意味が「損した」から「天井が近づいた」に反転する**点にある。失敗してもプレイヤーは前に進んでいると感じられるため、カジュアル層でも回し続けられる。

**連鎖ボーナス**:3連続で成功すると大成功の確率が上がる。連続で回す理由が増え、「ここで止めたらもったいない」という継続動機が生まれる。

なお、**失敗しても装備は消えず、強化段階も下がらない**設計とする(素材の消費のみ)。ロストを伴う強化はカジュアルタイトルでは耐えられない。

## 3-2. 確定チケット

インゲームのストック1個を**金以上確定**にするチケットアイテムを用意する。入手経路はログインボーナスやドロップとする。

このアイテムの効果は、使った後ではなく**持っている時点から始まる**。「次のランでこれを使おう」という予定がプレイヤーの頭に残り、ログインとランの開始動機になる。効果が未来にあるアイテムは、所持しているだけで期待を発生させ続ける。

## 3-3. ドロップ率UP状態の継続

最高レアを引いた直後などを条件に、**「ドロップ率UP中 残り3回」**という状態が発生する。ホーム画面の色調やBGMが変わり、現在その状態にあることが一目で分かるようにする。

これは遊技機の確変に相当し、「今やめると損をする」という損失回避を働かせて次のランを促す。

**残り回数の単位は「時間」ではなく「ラン数」にすることを推奨する**。時間制限方式は短期の稼働数値こそ伸びるが、プレイヤーの生活時間を人質に取る設計であり、カジュアルタイトルには過剰である。ラン数制なら、都合のいいタイミングで消化できる。

## 3-4. インベントリでの装備差分表示

武具インベントリにおいて、**今装備しているものと比べてどれだけ数値が上がるか**を一覧上で示す。

表示は2段階で用意する。まず、リストを眺めるだけで判別できる**緑の▲マーク**(現装備より強い)。これは数値を読まなくても分かるため、装備選びの認知コストをほぼゼロにできる。次に、選択時や装備時に出る**「+123 ↑」の具体的な差分値**。こちらはエフェクトとして飛ばすと、数値の変化が快感として処理される。

数値が苦手なプレイヤーはマークだけで判断でき、詰めたいプレイヤーは差分値を読める。**同じ情報を2つの解像度で提供する**ことで、両方の層に届く。

## 3-5. 一括最強装備ボタン

ボタン1つで全部位を最適な装備に差し替える。差し替えと同時に**戦闘力の数値が大きくカウントアップ**し、キャラクターにオーラのエフェクトが発生する。

本提案において、この瞬間が**「強くなった」を最も強く実感させる箇所**である。インゲームで溜め、リザルトで開けた成果が、ここで一気に数字と見た目に変換される。遊技機で言えば、積んだ出玉を一度に流す瞬間に相当する。

ビルドを組みたいプレイヤーのために、個別装備と「元に戻す」操作は必ず残す。

## 3-6. 試し切りへのショートカット

装備画面から**直接「試し切り」へ移動できるボタン**を置く。新しい装備で実際に敵を殴り、手応えを確かめられるようにする。

これは**即時反映しないという本作の制約を、最も直接的に埋め合わせる仕掛け**である。戦闘力の数字がいくら上がっても、それは抽象的な情報でしかない。実際に殴って、以前より速く敵が崩れるのを見て初めて「強くなった」は身体的な実感になる。

このとき、**前回の記録との差分を表示**すると効果が跳ね上がる。「前回より+2,400」という数字が、装備更新の成果を具体的な値として突きつける。4人で同時に殴れるようにすれば、自然に比べ合いが発生する。

装備画面からの導線を短くすることが肝要である。メニューを何階層も潜らせると、この機能は使われずに終わる。

## 3-7. 次の目標値の提示

「◯◯クエスト 推奨戦闘力 ◯◯◯◯◯ まであと ◯◯◯」という表示を出す。

**表示するタイミングが重要**で、一括最強装備で戦闘力が上がった**直後**に見せる。達成感の余韻が残っている瞬間に次の目標を提示することで、満足感がそのまま次のランへの動機に変換される。あと少しで届くという状態は、それ自体が強い牽引力を持つ。

## 3-8. レアリティ表現の多段化

武具アイコンの背景(レアリティ表現)について、**同じ「金」の中にもエフェクトやアニメーションで差分をつける**。

レアリティ階層は運用が進むと必ず飽和する。最上位を引いた後に「これ以上はない」と感じさせてしまうと、収集の動機がそこで止まる。同じ金の中に見た目の個体差があれば、**金を引いた後も「もっと良い金」を探し続ける**動機が残る。

これはレアリティ区分を増やすのとは異なり、システム側のバランスに影響を与えずに見た目の階層だけを深くできる。実装コストに対して、収集欲を延長する効果が大きい。

# 4. 全体を貫く設計ルール

3シーンを通して守るべき原則を以下に定める。

**演出は抽選結果を変えない。** 抽選はアイテムの取得時点で確定させ、以降の演出は「開示の順序と速度」のみを制御する。これを崩すと実装が破綻し、不具合の温床になる。

**変化は必ず上方向のみ。** 保留の昇格もリザルトの昇格も、上げることしかしない。高く見せて下げる演出は、遊技機の文法に馴染みのないカジュアル層には不信としか映らない。降格が存在しないなら、初期表示は「最低保証値」として一貫した説明ができる。

**下手なプレイヤーを罰しない。** 倍率もボーナスも、減点型ではなく加点型で設計する。4人のうち2人が置いていかれる構造を作ると、パーティは解散する。

**期待度は常に見せる。** 中身は隠してよいが、期待度を隠してはいけない。情報がゼロの状態は、アクションの手応えを直接損なう。

**繰り返し通過する画面には必ずスキップを用意する。** そのうえで、見せ場だけはスキップ不可区間として確実に通す。

# 5. 補足:アウトゲームの抽選をもう1つ増やす案(任意)

武具をリザルトで全て確定させる方針により、アウトゲームに残る抽選は**強化のみ**となる。強化素材が尽きた時点で、アウトゲームで回せるものがなくなる構造である。

ここを補うなら、**強化素材だけを未開封のまま持ち帰る**案が考えられる。インゲームで「未鑑定の原石」のようなサブアイテムがドロップし、アウトゲームで開けると強化素材が出る。まれに大当たりの素材が出る。

この形であれば、武具のリザルト体験を薄めることなく、アウトゲームに開封の楽しみを1つ追加できる。しかも開けた結果がそのまま強化の弾になるため、**「開ける → 強化する → もう1回」**という導線が自然につながる。複数個を溜めてから一度に開ける「まとめ開封」にすると、演出の山としても機能する。

優先度は高くないが、アウトゲームの滞在時間が想定より伸びなかった場合の打ち手として保持しておく価値がある。

# 6. 実装の優先順位

| 段階 | 内容 | 理由 |
|---|---|---|
| **第1段階** | HUDストック表示 / リザルトの1個ずつ開示 / 一括最強装備+戦闘力表示 | この3つで「溜める → 開ける → 強くなる」の1周が成立する。他の施策は全てこの上に乗る |
| **第2段階** | ドロップ倍率とRUSH / 強化抽選(天井・連鎖込み) / 装備差分表示 / 試し切り導線 | 抽選回数と操作の手応えを増やす。効果が最も出る層 |
| **第3段階** | ストック昇格 / 復活 / 予告の多層化 / ドロップ率UP継続 / 推奨値表示 | 単体では成立しないが、あると体験の密度が大きく上がる |
| **第4段階** | 一発告知音の共有 / 虹エフェクトの敵 / レアリティ多段化 / 満タン時の仲間への譲渡 | マルチと収集の価値を深める。基盤が動いてから乗せる |

# 検証ブロック

**妥当性**:参照している遊技機の演出文法(保留、先読み、昇格、復活、確変)は長期間の実運用で射幸性が検証されており、非即時反映という制約をそこへ写像する構造的整合性は高い `[ESTIMATE]`。ただし個々の施策の効果量および本作のプレイヤー層における反応は未計測である `[HYPOTHESIS]`。

**制約**:演出が抽選結果を変えない原則を全施策で維持する必要がある。「初期表示を低く見せる」表現は、降格を一切作らないことで整合性を担保している。有償通貨がドロップ率や強化に関与する場合は、確率表示等の法令対応が別途必須となる。リザルトにおける4人分の開示方式は未決定であり、テンポ設計の要点となる。

**改善余地**:各演出の信頼度テーブルの具体値、RUSHの発生頻度と持続時間、天井までの回数、試し切りにおける比較基準(前回装備か、ランの開始時点か)、リザルト全体の尺の上限。いずれも実測なしには確定できない。

**次アクション**:第1段階の3施策でプロトタイプを構築し、リザルトの滞在時間、一括装備ボタンの使用率、1セッションあたりのラン数を基準値として取得する。その後、第2段階の施策をA/Bで順次追加し、各施策の増分効果を個別に測定する。
